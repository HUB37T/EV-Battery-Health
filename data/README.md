# Data

| Folder | Contents | In Git |
|---|---|---|
| `raw/` | Original Kaggle archive, never modified | No |
| `processed/<recipe>/` | `train/validation/test.npz` with `X`, `y_scaled`, `y_original`, IDs and feature names | No |
| `splits/battery_split.csv` | Split manifest by `battery_id` (seed 42, 70/15/15 of batteries) | Yes |

## Getting the raw data

1. Download the archive from [Kaggle: EV Battery Health & Degradation Dataset](https://www.kaggle.com/datasets/vinay24baghira/ev-battery-health-and-degradation-dataset).
2. Extract **all three files** into `data/raw/` without renaming them:
   - `ev_battery_health.csv`
   - `README.md`
   - `data_dictionary .csv` (the space before `.csv` is part of the original name)

The audit rejects a CSV whose SHA-256 differs from the audited version
(`cacdf6af…8218d`) and refuses to overwrite an existing split manifest. The source
describes the data as synthetic and licensed CC0. Details are in the
[dataset card](../docs/DATASET_CARD.md).

`processed/` is regenerated by `python -m ev_battery preprocess`.
